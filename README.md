# ATM Interface System

A secure Java-based ATM simulator with enhanced features for real-world banking operations.

## Key Features
- SHA-256 encrypted PIN authentication
- Real-time fund transfers between accounts
- Transaction history with timestamps
- File-based account persistence
- Auto-clearing CLI interface

## Tech Stack
- **Core**: Java 11
- **Security**: SHA-256 hashing
- **Storage**: File I/O for accounts/transactions
- **Architecture**: OOP (4-class structure)
